## 📖 About The Project

**Laju Perubahan** is more than just a band — it's a statement. This repository contains the official website for the band, built as a personal project that combines a love for music with hands-on web development skills.

The site serves as a central hub for band information, discography, and connecting with the audience — fully designed and developed from scratch using a modern full-stack approach.

> *"Laju Perubahan" — Indonesian for "Rate of Change." A name that reflects constant growth, both musically and technically.*

---

## ✨ Features

- 🎵 **Band Profile** — Story, members, and the band's journey
- 🎶 **Discography** — Music catalog and track listings
- 📸 **Gallery** — Photos from performances and behind-the-scenes
- 🗓️ **Event / Gig Info** — Upcoming shows and past performances
- 📬 **Contact Section** — Easy way for fans and organizers to reach out
- 📱 **Responsive Design** — Fully optimized for mobile and desktop

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/) v18+
- [Python](https://www.python.org/) 3.10+
- [Git](https://git-scm.com/)

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/JihanIsfalana-oss/LajuPerubahan.git
cd LajuPerubahan
```

**2. Set up the frontend**

```bash
cd frontend
npm install
npm run dev
```

**3. Set up the backend**

```bash
cd ../backend
pip install -r requirements.txt
python main.py
```

**4. Open in your browser**

```
http://localhost:3000
```
